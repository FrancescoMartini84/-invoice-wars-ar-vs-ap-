## Scenario

A customer receives an invoice for $2,650 but
pays only $2,400, claiming $250 in damaged goods.

AR and AP must investigate the discrepancy before
issuing adjustments or closing the invoice.

## Features

- Outstanding balance calculation
- Short-payment identification
- Dispute management
- Credit memo verification
- Interactive decision-making exercise
- Python bookkeeping calculation
- Browser-based application
